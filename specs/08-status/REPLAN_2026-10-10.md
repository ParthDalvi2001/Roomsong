## 4. Room signature (new; Should-have S1, built only if the device spike T-104 shows planes/labels are available)
- **Definition:** a pure function `roomSignature(features) → { keyRoot, mode, tempo, reverbSize, starterVoices[3], paletteSeed }`, deterministic and **quantised** (so small noise in detection never changes the result; the same room always gives the same song).
- **Inputs (`RoomFeatures`):** table height (m), table area (m²), room floor area (m²), wall count, ceiling height (m), largest wall width (m), detection level (1–4). Unknown fields → defaults.
- **Fallback "Wanderer" signature** when level ≥3 or features unknown: C major pentatonic, 84 BPM, medium reverb, starter voices Bell/Pad/Pluck.
- **Tuning ripple (the "this surface made this note" moment):** on placement, a light ripple crosses each detected surface in turn (table → nearest wall → ceiling if any) and each rings one note of the room chord. Audible ≤5 s after placement. Reduced-motion: surfaces glow in sequence without the sweep.
- **Re-tune:** on each session start the signature is recomputed; a different room re-tunes the garden in place (plants keep cells; pitches follow the new mode).
- New IDs: **FR-ROOM-10** (features extraction), **FR-ROOM-11** (signature function), **FR-ROOM-12** (tuning ripple), **FR-ROOM-13** (re-tune on session start). **ADR-005-room-signature.md**. Decision **D-010**.
- Seasons (weekly mode changes) are **cut**; the room decides mode. Palette = fixed bioluminescent set, tinted by `paletteSeed`.

## 5. Scope (new MoSCoW; replaces PRD §6)
### Must (ship or fail)
- M1 Enter XR hands-only; placement chain L1 table → L2 any surface 0.5–1.1 m → L3 hit-test → L4 floating bed. Reach ≤0.75 m.
- M2 Palm-up seed → pinch-carry → plant → snap (5×16 annulus) → tide plays; **5 voices** (Bell, Pad, Pluck, Bass, Choir); scale quantised; limiter; HRTF spatial audio.
- M3 Shaping: **pull** (height = volume + sustain), **drag** (move cell), **drag off the bed** to remove (with 5 s undo petal). *(twist, flick: cut)*
- M4 Listen mode: palms-out **or Listen orb**; dim; **aurora halo** over the bed; auto-end 10 min; wake by pinch/palm-to-face.
- M5 Local save/restore (IndexedDB); corrupt-save safety.
- M6 Onboarding: ≤6-word captions, first sound ≤20 s, 3-plant loop ≤90 s.
- M7 Perf: ≥72 fps target / ≥60 floor on Quest 3 (**verified only once a headset exists**); emulator budgets (draws/tris/JS ms) enforced meanwhile.
- M8 Accessibility: **one-hand mode**, **high contrast**, **beat ring**, **reduced motion**; **gaze-dwell select + Listen** (no sliders).
- M9 FoV-safe layout; seated reach.
### Should
- S1 Room signature + tuning ripple + re-tune (§4) — gated on T-104.
- S2 Vines of light to the nearest wall in Listen mode (halo remains the fallback).
- S3 Daily seed + overnight growth stages (0/1/3/7 days) with `fakeDay` for the video.
- S4 Persistent anchor restore (fallback = re-place by chain).
- S5 Shimmer voice (6th).
### Could (only if G2 passes with slack)
- C1 Listen-mode variations · C2 gaze-dwell sliders for pull · C3 hue shaping via a settings control.
### Cut (won't do this competition)
- Wrist twist; flick; weekly seasons; Seed Codex; controller support; offline service worker; garden image export; "Gardener" helper; diagrams task; traceability script; 7 rings; bed radius options (single 0.12–0.30 m bed; height ±10 cm stays).
